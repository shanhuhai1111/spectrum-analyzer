# 实时频谱分析仪 / 简易示波器

一个**纯软件**的信号采集与频谱分析工具：用电脑自带麦克风（声卡）当作 ADC，
实时显示时域波形和 FFT 频谱，并自动标出峰值频率（音高检测）。

> 电子信息工程视角：本项目 = 声卡采样（ADC）+ 加窗 FFT（频谱分析）
> + 峰值检测（音高估计）。

## 功能

- 上：**时域波形** —— 声卡采集的原始音频流
- 下：**FFT 频谱** —— 加汉宁窗后做 FFT，幅度转 dB，并标出最大峰值频率
- `--demo` **演示模式** —— 不接麦克风，用 440Hz + 1000Hz 合成正弦波演示
  （440Hz 正好是钢琴 A4 音，可验证音高检测）
- 支持命令行选择输入设备、采样率、频率分辨率

## 安装

需要 Python 3.9+，然后：

```bash
pip install -r requirements.txt
```

`sounddevice` 底层是 PortAudio，安装包自带 Windows 预编译二进制，无需额外配置。

## 运行

```bash
# 用系统默认麦克风
python main.py

# 先看一下有哪些输入设备（会打印设备列表），再指定索引
python main.py --device 2

# 没有麦克风/不想开麦：合成信号演示
python main.py --demo
```

用麦克风时朝话筒哼一声/吹口气，频谱上就能看到能量抬升；`--demo` 模式下
频谱应该稳定显示 440Hz 和 1000Hz 两根谱线，标题里的峰值频率约等于 440Hz。

## 参数说明

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `--device` | 默认输入设备 | 输入设备索引 |
| `--rate` | 44100 | 采样率 (Hz) |
| `--block` | 1024 | 每个音频块采样点数 |
| `--blocks` | 8 | 每帧拼接块数（= FFT 点数，越大频率分辨率越高、刷新越慢） |
| `--fmin` | 80 | 峰值检测最低频率 |
| `--fmax` | 20000 | 峰值检测最高频率 |
| `--demo` | 关 | 演示模式（合成信号） |

几个关键换算（`--block 1024 --blocks 8` 时，FFT 点数 N = 8192）：

- 时间窗长度 = N / fs ≈ **186 ms**
- 频率分辨率 Δf = fs / N ≈ **5.4 Hz**

## 工作原理

```
声卡（麦克风）--采样--> 音频块 --拼接--> 一段波形 --加窗FFT--> 幅度谱 --log--> dB频谱
                                                                    └--峰值检测--> 音高
```

1. **采集**：`sounddevice.InputStream` 回调式采集，底层音频线程往环形缓冲
   写入数据块，GUI 线程随时取走最近几块，互不阻塞（`audio_stream.py`）。
2. **加窗 FFT**：对整段信号乘汉宁窗后做 `numpy.fft.rfft`，只取正频率，
   乘 `2/N` 归一化得到幅度。汉宁窗增益约 0.5，所以谱峰幅度 ≈ 真实幅度 × 0.5（`dsp.py`）。
3. **峰值检测**：在 `[fmin, fmax]` 频带内取幅度最大点作为音高估计。
4. **实时刷新**：`matplotlib.animation.FuncAnimation` 每 30ms 重绘一次。

## 代码结构

```
audio_stream.py   音频采集（声卡 ADC）+ 演示信号源
dsp.py            数字信号处理（加窗 FFT / dB 转换 / 峰值检测）
viz.py            实时绘图（时域 + 频域双子图，GUI 主循环）
main.py           程序入口与命令行参数
```

## 扩展建议

1. **更稳的音高检测**：当前是"取最大谱峰"，对纯音很好，对乐器/人声不准。
   换成**自相关法**或**倒谱法**做基频检测，再跟当前结果对比——这就是一篇
   可以写进简历的"算法对比实验"。
2. **频谱瀑布图（spectrogram）**：随时间推移把频谱叠成一幅二维图，
   能直接看到"频率随时间变化"，很直观。
3. **加一个界面**：用 `tkinter` 加开始/暂停/选设备的控件，或换 `pyqtgraph`
   把刷新率从 30fps 提到 60fps+。
4. **实时滤波**：在采集和 FFT 之间插入一个 FIR/IIR 数字滤波器
   （可以自己用卷积实现，不用 scipy），加"低通/高通/带通"切换。

## 常见问题

- **没有音频设备报错**：用 `python main.py --demo` 即可，不影响看效果。
- **采样率不兼容**：部分声卡不支持 44100，可以换 `--rate 48000`。
- **波形不动或全是噪声**：确认选对了输入设备，麦克风权限在系统设置里打开。
